Python nổi tiếng vì cú pháp dễ đọc, dùng nhiều trong phân tích dữ liệu, tự động hóa và web.
Khóa học giới thiệu biến, điều kiện, vòng lặp, list, dict và hàm.

Ô chạy thử chỉ hỗ trợ JavaScript và SQL, vì vậy code trong khóa là **minh họa**; bạn luyện tập qua các câu hỏi dự đoán kết quả.

Java là ngôn ngữ hướng đối tượng có kiểu tĩnh, dùng nhiều trong hệ thống doanh nghiệp và ứng dụng Android.
Khóa học tập trung vào tư duy hướng đối tượng qua cú pháp Java.

Ô chạy thử chỉ hỗ trợ JavaScript và SQL, vì vậy code trong khóa là **minh họa**; bạn luyện tập qua các câu hỏi dự đoán kết quả.
